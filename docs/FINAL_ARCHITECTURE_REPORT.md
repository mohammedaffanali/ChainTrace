## 2. 7-Signal Explainable Attribution Formula

The core algorithm computes a deterministic weighted score $S_{total} \in [0, 100]$:
$$S_{total} = \sum_{i=1}^{7} w_i \cdot s_i$$

Where:
- $w_1 = 0.24$ (Transaction Proximity & Hop Distance)
- $w_2 = 0.22$ (Deposit Signature Match)
- $w_3 = 0.18$ (Wallet Cluster Association)
- $w_4 = 0.15$ (Regulatory Registry Status)
- $w_5 = 0.10$ (Cross-Chain Continuity)
- $w_6 = 0.07$ (Behavioral Ingestion Heuristics)
- $w_7 = 0.04$ (Historical LEA Intelligence)

**Confidence Bands**:
- $\ge 90\%$: `VERY_STRONG_CANDIDATE`
- $75\% - 89.9\%$: `STRONG_CANDIDATE`
- $60\% - 74.9\%$: `MODERATE_CANDIDATE`
- $40\% - 59.9\%$: `WEAK_CANDIDATE`
- $< 40\%$: `INSUFFICIENT_EVIDENCE` (Zero-guessing triggered)
